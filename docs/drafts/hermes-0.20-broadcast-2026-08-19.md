## 1. 语音交互

以前 Hermes 只能看到文字。现在 Hermes 听得到、说得出。

- **流式 TTS** — 你让我用语音回复，我边说边生成，不用等我说完。
- **语音打断** — 你听到一半觉得不对，直接说"停"，我立刻闭嘴。
- **唤醒词** — 设定一个词，比如 "Hey Hermes"，喊一声就激活。

想用：发语音消息给 Hermes，Hermes 用语音回复你。

━━━━━━━━━━━━━━━━━━━━━━

## 2. Agent 互联（A2A v1.0）

一个 Hermes 可以把任务委托给另一个 AI（Claude、GPT、Gemini、或者另一个 Hermes）。

想用：你让我"分析这份财报"，我发现自己想再问 GPT 一个细节，我可以**直接**派任务给 GPT，把答案拿回来给你。整个过程你不会看到中间过程，只有最终的分析结果。

━━━━━━━━━━━━━━━━━━━━━━

## 3. 出站 Webhooks

以前只能等你发消息，Hermes 才会回复。
现在 Hermes 可以**主动**推送给用户。

- 任务完成 → 自动发到 Slack / Discord / Notion
- 定时报告 → 每周一早上自动发邮件
- 事件触发 → 价格突破阈值时，Hermes 主动 push 通知

想用：如果你有定时任务（比如每天 9am 跑 portfolio 检查），报告可以自动发到你的 Telegram，不用每次手动查。

━━━━━━━━━━━━━━━━━━━━━━

## 4. 带引用回答

以前我说"根据记忆里的某条数据，X 是这样"，你追问"你怎么知道"，我只能回忆。

现在：
- 我说的每个事实后面带编号 [1, 2, 3]
- 每个编号能追溯到具体的 source（文档、记忆条目、过往消息）
- 我**不能虚构** —— 如果没有引用可追，我宁可不回答

想用：问"为什么你说 X"，我会直接给你引用链接，点开就能看到源头。

━━━━━━━━━━━━━━━━━━━━━━

## 5. Desktop App

如果你把 Hermes 装在桌面端，现在是真正的桌面 app 体验：

- 系统托盘图标
- 跟系统通知中心集成
- 拖文件进 Hermes
- 一键安装社区插件

━━━━━━━━━━━━━━━━━━━━━━

## 6. 启动更快

- 冷启动少卡 14 秒
- 响应更快
- 跨重启上下文不丢（之前如果重启 Hermes，你之前的对话状态可能丢失）

━━━━━━━━━━━━━━━━━━━━━━

## 7. 稳定性

- TCP 黑洞端点不再被反复重试 → 网络抖动少
- 微信多 bot 路由
- Discord 工具消息路由到正确 thread，不会串到主频道
- 中文/日文/韩文触发器更准确
- 配置统一从 yaml 读，部署更简单
- 端口冲突保护

━━━━━━━━━━━━━━━━━━━━━━

## 8. 怎么样开始用

所有功能都已经默认启用。你不用做任何事。

如果想试试：
- 发语音消息 → Hermes 语音回复
- 问"为什么你说 X" → 带引用
- 设个定时任务要推送 → 自动发

如果要关掉某个功能，说一声就关。

━━━━━━━━━━━━━━━━━━━━━━

## 9. 这次升级特别在哪

不只是 Hermes 一个人升级。这是整个 AI agent 社区的里程碑。

- A2A v1.0 是新标准 —— 让所有 agent 之间的协作更顺畅。
- Voice 让"自然交互"成为现实。
- 带引用回答是减少"幻觉"的工程解决方案。

如果你平时只用文字消息，当前体验不会变差 —— 这些升级是**额外**的能力。
