# v1.14.11 — Memmy-inspired skill extraction pipeline

## Overview

This release adds two new scripts that together implement a deterministic
first-pass classification + importance-boost pipeline for astor memories.

**Reference**: Inspired by Memmy's "skill extraction" pattern (from the
2026-09-09 WeChat article "让所有 AI 都记得同一个你") — Memmy's pipeline
clusters repeated procedural patterns into reusable skills. Astor's
implementation uses deterministic regex rules for v1, with LLM-assisted
classification planned for v1.15.

## Ship contents

### 1. `scripts/astor_initial_report.py`

A "first-meeting report" tool that summarizes a user's astor state:
- Top N facts by importance (grouped by kind)
- Last M events (with relative timestamps)
- Coverage stats (active facts, tombstoned, top namespaces)
- Markdown output for human reading

**Usage**:
```bash
python scripts/astor_initial_report.py --user admin --tier private \
    --top-facts 20 --last-events 15 \
    --out docs/onboarding/admin-initial-report.md
```

### 2. `scripts/astor_skill_extractor.py`

Deterministic classifier that reclassifies `kind=fact` rows into more
specific kinds (`rule`, `decision`, `user_preference`, `lesson`,
`failure_pattern`) based on content signals.

**Classification rules** (in priority order):
1. R-class / locked patterns → `rule`
2. "用户偏好是 X" / "用户偏好: ..." references → `rule` (negative pattern, overrides decision)
3. "用户决策/决定/授权" → `decision`
4. "用户偏好/喜欢/倾向/允许" (not in quotes) → `user_preference`
5. "用户(从不|总是|经常|不要|应该)" (not in quotes) → `user_preference`
6. Fact starts with failure pattern → `failure_pattern`
7. "[LESSON]/[教训]/session 终局/R-class canonical" → `lesson`
8. Default → `fact` (no change)

**Output**:
- JSON file with reclassifications and skill-cluster proposals
- `--dry-run` to preview without modifying DB

**Usage**:
```bash
python scripts/astor_skill_extractor.py --user admin --tier private \
    --min-imp 0.85 --dry-run --out reclassify.json
```

### 3. `scripts/astor_importance_audit.py`

Boosts `importance` for facts that contain R-class / locked / lesson /
iron-rule content but were stored with default importance (0.5).

**Boost signals** (in priority order):
| Signal | Target importance |
|---|---|
| R-class canonical / locked / R### (locked) | 0.95 |
| (locked YYYY-MM-DD) | 0.9 |
| [LESSON]/[教训] prefix | 0.85 |
| Iron Rule N | 0.85 |
| Tombstone audit fact | 0.8 |
| 教训/takeaway / 用户(从不/总是) / ends with (verified) | 0.7 |

**Usage**:
```bash
python scripts/astor_importance_audit.py --user admin --tier private \
    --dry-run --report importance-boost.md
```

### 4. Unit tests

- `test_astor_skill_extractor.py` — 13 tests covering R-class, decision,
  user preference (quoted vs unquoted), failure (start vs middle), lesson
  patterns.
- `test_astor_importance_audit.py` — 9 tests covering each boost signal.

## Pipeline workflow (recommended)

```bash
# Step 1: Boost importance for R-class content
python scripts/astor_importance_audit.py --user admin --tier private \
    --dry-run --report importance-boost.md

# Step 2: Reclassify after boosting (will find more candidates)
python scripts/astor_skill_extractor.py --user admin --tier private \
    --min-imp 0.85 --dry-run --out reclassify.json

# Step 3: Apply both (after review)
python scripts/astor_importance_audit.py --user admin --tier private
python scripts/astor_skill_extractor.py --user admin --tier private \
    --min-imp 0.85
```
