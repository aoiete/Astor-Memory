## Translation conventions

- **Terms**: technical terms stay in English (ACL, bus, forge, nest,
  tier, scope). First occurrence in a Chinese doc gets the English
  original in parentheses, e.g. "3 层隔离 (3-tier isolation)".
- **Code**: all code samples (`bash`, `python`, `json`) stay in
  English — commands, field names, API endpoints are all English.
- **Section order**: Chinese and English versions have identical
  heading order, so cross-references work.
- **Links**: Chinese docs use Chinese filenames in relative links,
  e.g. `[架构](architecture.zh-CN.md)`.

## Contributing a translation

Want to translate a doc into a new language? Welcome!

1. Fork the repository
2. Copy the English source; rename to `.<lang>.md`
   (e.g. `architecture.de.md` for German)
3. Translate sections, keeping structure aligned
4. Add a row to the table above in `docs/i18n.md`
5. Open a PR → `main`

Detailed conventions: [`contributing.md`](contributing.md)
§ "Documentation i18n".
