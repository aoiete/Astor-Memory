# 多语言文档 / Internationalization

Astor-Memory 文档目前支持两种语言:

| 文档 | 英文 | 中文 |
|---|---|---|
| 项目入口 | [`README.md`](../README.md) | [`README.zh-CN.md`](../README.zh-CN.md) |
| 架构 | [`architecture.md`](architecture.md) | [`architecture.zh-CN.md`](architecture.zh-CN.md) |
| API 参考 | [`api.md`](api.md) | [`api.zh-CN.md`](api.zh-CN.md) |

## 翻译约定

- **术语**:技术术语优先保留英文(例如 ACL、bus、forge、nest、tier、scope)。中文翻译在首次出现时给出英文对照(例如 "3 层隔离 (3-tier isolation)")。
- **代码**:所有代码示例(`bash`、`python`、`json`)保持英文,因为命令、字段名、API 端点都是英文。
- **章节顺序**:中文版的章节顺序与英文版完全对齐,便于交叉引用。
- **链接**:中文版中的相对链接指向中文文件名(例如 `[架构](architecture.zh-CN.md)`)。

## 贡献翻译

欢迎贡献其他语言的翻译(例如 `docs/architecture.de.md` 德文版)!

1. Fork 仓库
2. 复制英文文档,把 `.md` 后缀改为 `.<lang>.md`(例如 `architecture.de.md`)
3. 翻译章节,保持结构对齐
4. 在 `docs/i18n.md` 中添加新行
5. PR → main

详细的翻译约定见 [`contributing.md`](contributing.md) §"Documentation i18n"。
